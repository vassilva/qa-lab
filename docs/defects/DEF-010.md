## Summary
The "Executed quantity vs. order" query worked on SQLite but failed on PostgreSQL with
`ERROR: column "executado" does not exist`.

## Analysis and fix
PostgreSQL does not allow a SELECT alias in HAVING. Fix: repeat the expression
`HAVING o.qty - o.remaining <> COALESCE(SUM(t.qty),0)`. Lesson: always validate SQL on the same database engine as production.

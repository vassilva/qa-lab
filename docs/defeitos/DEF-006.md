## Resumo
Depois da regressão BDD, o ambiente QA fica com os dados do último cenário e com a data de negócio 2026-11-06,
em vez da data de hoje. Quem usar o QA a seguir encontra dados que não criou.

## Passos para reproduzir
1. Correr o pipeline até ao fim.
2. Abrir `localhost:8000`: a data de negócio é 2026-11-06 e há ordens e negócios de teste.

## Resultado esperado
Os testes deixam o ambiente como o encontraram (sem dados de teste, data de negócio do dia).

## Resultado obtido
No build seguinte, o Smoke QA mostra `data de negócio 2026-11-06`, enquanto o UAT mostra a data de hoje (2026-11-03).

## Análise e correção
Os cenários limpam o ambiente **antes** de cada teste, mas não **depois** do último.
Correção (ramo `fix/DEF-006-bdd-repoe-ambiente`): hook `after_all` no `features/environment.py` que reinicia o QA no fim.
A limpeza só corre depois de confirmado que o ambiente não é UAT. Ver `docs/qa/validacao-de-correcoes.md`.

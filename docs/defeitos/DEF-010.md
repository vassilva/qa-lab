## Resumo
A query "Quantidade executada vs. ordem" funcionava em SQLite mas falhava em PostgreSQL com
`ERROR: column "executado" does not exist`.

## Análise e correção
O PostgreSQL não permite usar um alias do SELECT no HAVING. Correção: repetir a expressão
`HAVING o.qty - o.remaining <> COALESCE(SUM(t.qty),0)`. Lição: validar sempre o SQL no mesmo motor de base de dados da produção.

## Summary
After the BDD regression, the QA environment keeps the data from the last scenario and the business date 2026-11-06
instead of today's date. Whoever uses QA next finds data they did not create.

## Steps to reproduce
1. Run the pipeline to the end.
2. Open `localhost:8000`: the business date is 2026-11-06 and there are test orders and trades.

## Expected result
The tests leave the environment as they found it (no test data, today's business date).

## Actual result
In the next build, the QA smoke shows `business date 2026-11-06`, while UAT shows today's date (2026-11-03).

## Analysis and fix
The scenarios clean the environment **before** each test, but not **after** the last one.
Fix (branch `fix/DEF-006-bdd-repoe-ambiente`): an `after_all` hook in `features/environment.py` that resets QA at the end.
The cleanup only runs after confirming that the environment is not UAT. See `docs/qa/fix-validation.md`.

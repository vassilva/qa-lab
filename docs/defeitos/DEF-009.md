## Resumo
O build parava com `E: Package 'ttyd' has no installation candidate`: o terminal web não existe nos repositórios do Debian 12.

## Análise e correção
Correção: instalar o binário oficial do projeto ttyd (versão 1.7.7), escolhendo a arquitetura com `uname -m`
(commit `36de153`). Validação: build completo e `ttyd --version` durante o build.

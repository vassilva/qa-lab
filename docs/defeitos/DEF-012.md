## Resumo
O teste `tests/integration/test_openapi.py` lê os contratos `contracts/*.openapi.yaml` com `import yaml`,
mas a biblioteca PyYAML não estava em `requirements.txt`. Dentro da imagem, o pytest parou na recolha dos testes
e o pipeline não passou do primeiro estágio de testes. A versão não chegou a QA nem a UAT.

## Evidências
```
ERROR collecting tests/integration/test_openapi.py
E   ModuleNotFoundError: No module named 'yaml'
1 error in 0.67s
```

## Análise
"Funciona na minha máquina": no ambiente de desenvolvimento a PyYAML já estava instalada no sistema,
por isso os 86 testes passavam localmente. A imagem Docker só tem o que está declarado em `requirements.txt`.
É exatamente para isto que o pipeline corre os testes **dentro da imagem** que vai ser promovida.

## Correção
- `requirements.txt`: `pyyaml>=6.0`.
- Verificação feita: todas as bibliotecas importadas pelo projeto (app, testes, passos BDD, scripts) estão declaradas.

## Reteste
Build seguinte: o estágio "Testes de componente e API" recolhe e corre os 86 testes.

## Prevenção
Ação de melhoria: correr os testes num ambiente limpo (a própria imagem) antes de entregar uma versão,
e não só no ambiente de desenvolvimento.

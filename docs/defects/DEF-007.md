## Summary
Build #2 failed in the test summary stage, which runs **after** the UAT deployment, but the final message said
"The version does NOT go to UAT". A wrong message can lead to a wrong decision.

## Expected result
The message does not state anything that depends on the stage where the failure happened, or it says correctly whether the version reached UAT.

## Analysis and fix
Branch `fix/DEF-007-mensagem-falha-pipeline`: the message now explains that only failures in "QA · …" stages or earlier
stop the version from reaching UAT. The stages were renamed by environment (QA · / UAT ·) so this is visible in the Jenkins view.

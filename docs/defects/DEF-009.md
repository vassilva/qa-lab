## Summary
The build stopped with `E: Package 'ttyd' has no installation candidate`: the web terminal is not in the Debian 12 repositories.

## Analysis and fix
Fix: install the official ttyd binary (version 1.7.7), picking the architecture with `uname -m`
(commit `36de153`). Validation: full build and `ttyd --version` during the build.
